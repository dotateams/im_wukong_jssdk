# 实施任务

## 1. 协议与字段

- [ ] 梳理当前图片、GIF、自定义表情、视频、文件的 E2EE 媒体字段。
- [ ] 明确单文件格式和分片 manifest 都具备独立 `mediaKey` 与 `mediaKeyEnvelope` 两层结构。
- [ ] 明确大文件、小文件、分片文件、非分片文件都统一使用同一套媒体转发协议。
- [ ] 在单文件元数据和分片 manifest 中新增明文原始文件 MD5（`file_md5`）字段。
- [ ] 加密上传时计算明文文件整体 MD5 并写入元数据，明文不外发。
- [ ] 定义 `mediaKeyEnvelope` 的 version、alg、scope、AAD 和错误码。
- [ ] 定义缩略图部件在转发时的复用与重包字段（url、hash、iv、size）。

## 2. SDK 能力

- [ ] 新增 `canForwardE2EEMedia()`，判定输入为：可解源信封 + 存在可复用密文对象 + 目标频道密钥可用；不满足返回 typed reason。
- [ ] 新增 `unwrapMediaKeyEnvelope()`，从源消息信封解出 `mediaKey`。
- [ ] 新增 `wrapMediaKeyEnvelopeForChannel()`，按目标频道重新封装 `mediaKey`。
- [ ] 新增 `prepareE2EEMediaForward()`，生成目标频道的新媒体消息内容。
- [ ] 确保单文件和分片 manifest 都能复用密文对象。
- [ ] 确保缩略图与文件本体一起复用密文对象并在目标信封中重包，不重新上传。
- [ ] 加密频道转普通频道时，支持按 MD5 查询普通明文对象并优先复用。
- [ ] 源元数据缺失 `file_md5` 时，降级为本地解密计算 MD5 后再做复用查询，不跳过复用检查。
- [ ] MD5 未命中时，支持本地解密源密文文件并按普通文件重新上传。
- [ ] 确保不会复制源消息实例、源 sender key、源 message key 或源频道信封。

## 3. Web 接入

- [ ] 转发入口识别 E2EE 媒体消息，优先调用 SDK 快速转发接口。
- [ ] 加密频道转加密频道时显示快速完成，不展示重新上传进度。
- [ ] 加密频道转普通频道时先执行 MD5 查询，命中则直接复用普通文件。
- [ ] 依据 `canForwardE2EEMedia()` 的 typed reason 给出对应提示或按策略降级。
- [ ] 合并转发内嵌 E2EE 媒体逐条走快转/普通复用规则；含不可解媒体时给出定位明确的提示，不静默丢弃。
- [ ] 保持现有单条转发、多选逐条转发、合并转发和回复体验不被破坏。

## 4. 服务端配合

- [ ] 检查当前文件下载鉴权是否绑定源频道路径。
- [ ] 如有必要，新增密文对象引用记录，不复制 MinIO 文件。
- [ ] 对象引用创建做成幂等：以 (object_id, target_message_id) 唯一键，并发下不重复计数、不复制对象。
- [ ] 新增或复用接口，让目标消息可授权下载复用密文对象。
- [ ] 新增或复用普通文件 MD5 秒传查询接口，支持加密转普通时复用已存在明文文件。
- [ ] 增加引用记录清理策略，避免对象被误删或永久悬挂。
- [ ] 清理任务覆盖 E2EE 上传 session、分片记录、密文 chunk 对象、临时文件和无引用对象。
- [ ] 清理任务覆盖加密转普通解密重传中途取消/失败产生的临时明文对象。
- [ ] 清理任务删除分片信息和文件对象时保持一致，失败时可重试。

## 5. 测试

- [ ] SDK 单元测试：信封解包、重包、字段保留、`canForwardE2EEMedia` 各 false 分支。
- [ ] SDK 单元测试：明文 MD5 计算与写入，缺失时的降级计算。
- [ ] Web 静态测试：转发入口选择快速转发，失败提示正确。
- [ ] 接口测试：密文对象引用授权、目标频道成员下载权限。
- [ ] 接口测试：普通文件 MD5 命中和未命中分支。
- [ ] 接口测试：同一文件并发转发的引用幂等与计数正确性。
- [ ] 脚本测试：加密群到加密群、加密群到私聊、私聊到加密群。
- [ ] 大文件测试：512MB 分片文件快速转发，不重新上传 chunks。
- [ ] 小文件测试：非分片 E2EE 文件快速转发，不重新上传 object。
- [ ] 缩略图测试：带缩略图媒体转发到 E2EE 频道复用缩略图；转普通频道不携带 E2EE 缩略图信封。
- [ ] 合并转发测试：内嵌 E2EE 媒体逐条复用；含不可解媒体时错误定位正确。
- [ ] 加密转普通测试：MD5 命中时复用普通明文对象，MD5 未命中时重新上传，元数据缺 MD5 时降级计算。
- [ ] 清理测试：过期未完成分片上传会话清理后，session、chunk 记录、MinIO chunk 对象均被清理。
- [ ] 清理测试：加密转普通中途取消/失败后临时明文对象被清理。
- [ ] 浏览器真实测试：图片、GIF、自定义表情、普通文件、视频转发后可打开或下载。
